# Contributing

These pages apply to every contributor — human or AI. AI workers are pointed at
them by [`CLAUDE.md`](../../CLAUDE.md).

| Page | Covers |
| --- | --- |
| [Coding standards](coding-standards.md) | The rules all code is held to, in every language |
| [Coverage standards](coverage-standards.md) | 100% line and branch coverage, loud errors, tested doc examples |
| [Local development](local-development.md) | Prerequisites, running the gates, writing doc snippets |

The short version: **`scripts/gates.sh` must pass.** Everything a tool can
check, a gate checks; the rest is reviewed against the coding standards.
